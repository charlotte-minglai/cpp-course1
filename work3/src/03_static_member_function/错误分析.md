# 课堂练习三：静态成员函数——找出程序中的错误

## 课件原程序

```cpp
class Ctype {
private:
    int a;
    static int s;          // 定义私有的静态数据成员 s
public:
    static void Print();
    Ctype();
};

void Ctype::Print() {
    cout << "a=" << ++a << endl;   // 错误
    cout << "s=" << ++s << endl;   // 正确
}

Ctype::Ctype() {
    a = 0;
    s++;
    cout << "a=" << ++a << endl;
}

int Ctype::s = 0;

int main() {
    Ctype::Print();       // 未定义对象时，直接通过类名调用静态成员函数
    Ctype c1, c2;
    c1.Print();
    c2.Print();
    Ctype c3;
    c3.Print();
    return 0;
}
```

## 错误分析

1. **静态成员函数访问了非静态数据成员 `a`**（主要错误）。
   `Print` 被声明为 `static`，静态成员函数没有 `this` 指针，函数体内不能直接写
   `a` 或 `++a`。GCC 的报错是
   `invalid use of member 'Ctype::a' in static member function`。
   静态成员函数只能直接访问静态数据成员 `s`；如果要访问某个对象的 `a`，
   必须把对象作为参数传进来（如 `static void Print(Ctype &c)`），
   或者改用普通成员函数。

2. **在任何对象创建之前调用 `Ctype::Print()`**。
   如果 `Print` 仍然访问 `a`，此时根本没有对象可以提供 `a`，语义上也不成立。
   把 `Print` 改成只访问静态成员 `s` 之后，这一句就是合法的：
   静态成员函数不属于某个对象，可以在没有对象时通过类名调用。

3. **`s` 的自增位置需要明确语义**（不是编译错误）。
   构造函数里已经有 `s++`，`Print` 里又写 `++s`，于是 `s` 统计的是
   “构造次数 + Print 调用次数”，而不是“当前对象个数”。
   如果 `s` 的本意是对象计数，`Print` 中不应再自增，只输出即可。

## 改正方案

- `Print` 保留 `static`，函数体只访问静态成员 `s`，从而使
  `Ctype::Print()` 可以在没有对象时调用；
- 新增普通成员函数 `PrintA()`，通过对象访问 `a`；
- 这样既保留了“静态成员函数”的演示，又能打印普通成员 `a`。

改正后的完整代码见同目录的 `Ctype.h`、`Ctype.cpp`、`main.cpp`。
